# Reinstall
Computer Reinstall System

Updated the Lenovo for endeavouros instead of OpenSuse. (Will consider OpenMandriva in the Future)
The install system works without flaw on a install with no desktop.

Basic Instructions are as follows
Boot and Install from Live CD (USB) 
In the DE section choose none
Install system
Reboot at command prompt put in user name then password
run git
git clone https://github.com/thefrog-Argedion/Reinstall/
cd into clone repo
run reinstall.sh with the correct paramater. (see if this is executable, if not "chmod 755 reinstall.sh")
reboot when promted 
Prosper.
